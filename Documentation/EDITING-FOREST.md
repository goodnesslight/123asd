# Лес в Unity

Откройте `Assets/Scenes/BestStop.unity`, выключите Play и раскройте `Environment → Forest`.

- **Sky** — чистый цвет неба.
- **Far forest** — дальняя полоса хвойного леса.
- **Middle forest** — второй экземпляр полосы: другой размер, отражение и оттенок.
- **Near trees** — 12 отдельных елей, собранных из трёх вариантов.

Текущие Far forest и Middle forest используют обновлённый `ReferenceForest.png`: плотная ровная полоса в сине-зелёной палитре оригинального референса. Старый DistantForest сохранён как предыдущий вариант. Новый префаб: `Assets/Prefabs/Forest/ReferenceForest.prefab`. Ближние ели расставлены с высокими акцентами по краям и над крышей; формат экрана остаётся 16:9.

Ближние деревья теперь используют `ReferenceSpruce.png` с более плотными ветками по оригинальному референсу. Префаб: `Assets/Prefabs/Forest/ReferenceSpruce.prefab`. Рост экземпляров 310–480 единиц, привязан к высоте фасада; прежние слишком крупные варианты сохранены в проекте, но в текущей расстановке заменены.

Выберите дерево, нажмите W для перемещения, Ctrl+D для копии, Delete для удаления. Размер меняйте одинаково по X/Y в Transform. Sprite Renderer → Flip X отражает дерево; Color меняет оттенок. Сохраняйте Ctrl+S вне Play Mode.

Префабы: `Assets/Prefabs/Forest/SpruceTall.prefab`, `SpruceBroad.prefab`, `SpruceYoung.prefab`, `DistantForest.prefab`. Их можно перетаскивать в сцену. У каждого спрайта точка привязки снизу по центру.

Порядок отрисовки: небо −40, облака −30, дальний лес −24, средний −22, ближние ели −15, магазин и дорога −10. Деревья находятся за магазином; порядок можно изменить в Sprite Renderer → Order in Layer. Для леса GroundSort не используется.

`Assets/Art/Forest/StoreForeground.png` — слой магазина и земли с прозрачными участками вместо старого леса и неба. Деревья в него больше не нарисованы. Отдельные слои леса можно скрыть в Hierarchy, чтобы проверить это.

Используйте Best Stop → Build Windows (keep scene layout) для сборки. Add layered forest предназначен для первоначального создания; если группа Forest уже есть, команда не сбрасывает расстановку. Старые команды подготовки окружения для текущей сцены повторно не нужны.
