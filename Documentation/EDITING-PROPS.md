# Редактирование объектов в Unity

1. Откройте проект в Unity 6000.6.0f1 и сцену `Assets/Scenes/BestStop.unity`.
2. Остановите Play Mode. В Hierarchy раскройте `Environment → Props`.
3. Выберите PhoneBooth, IceMachine, TrashBin или YellowBollard. Клавиша **W** включает перемещение; позицию также можно задать через **Transform → Position X/Y**. Z оставляйте 0.
4. **Ctrl+D** дублирует выбранный объект. **Delete** удаляет его. Каждый жёлтый столбик — отдельный экземпляр.
5. Чтобы добавить объект заново, перетащите префаб из `Assets/Prefabs/Props` в Scene View. Размер можно менять через Transform → Scale, сохраняя одинаковые X и Y.
6. **Ctrl+S** сохраняет сцену. **Best Stop → Build Windows (keep scene layout)** собирает её с вашей расстановкой.

Для удобства включите **2D** в Scene View. Выделите фон и нажмите **F**, чтобы увидеть локацию. В редакторе фон и предметы видны без запуска игры. Персонаж и облака создаются при Play.

## Префабы

- `PhoneBooth.prefab` — телефонная будка.
- `IceMachine.prefab` — аппарат ICE вместе с табличкой 99¢.
- `TrashBin.prefab` — мусорка.
- `YellowBollard.prefab` — один жёлтый столбик, можно создать любое количество.
- `ElectricalCabinet.prefab` — электрический щиток вместе с верхним счётчиком и короткой соединительной трубкой. Перемещается, масштабируется и дублируется как остальные предметы.

Изображения хранятся в прозрачном атласе `Assets/Art/Props.png`. Четыре независимых Sprite-ассета лежат в `Assets/Art/Sprites`: PhoneBooth, IceMachine, TrashBin и YellowBollard. У всех точка привязки внизу по центру. Для расстановки удобнее использовать готовые префабы.

`GroundSort` автоматически задаёт порядок отрисовки по положению основания: объекты ближе к низу экрана перекрывают более дальние. Позиции и количество не задаются заново при запуске игры. Коллизии для этих декоративных объектов не добавлены.

Активный фон `Assets/Art/StoreBackgroundNoCabinet.png` не содержит нарисованных копий предметов, включая щиток: после перемещения на старом месте не остаётся дубликата. Меню Prepare editable scene предназначено для начальной подготовки; для обычной сборки используйте Build Windows. Если Environment уже существует, подготовка не восстанавливает удалённые экземпляры и не сбрасывает позиции.
