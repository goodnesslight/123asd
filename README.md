# Best Stop — Unity / C#

Небольшая игровая 2D-сцена по приложенному арту. Окружение перегенерировано под 16:9, облака — отдельные прозрачные спрайты с непрерывным движением. Персонаж — сгенерированный пиксельный спрайт с двенадцатью кадрами. Это прогулочная сцена: интерьер и сюжет не реализованы.

## Запуск

Готовая Windows-версия: `Builds/Windows/BestStop.exe`. Сохраняйте рядом всю папку BestStop_Data и библиотеки из папки сборки.

Unity Hub → Add project from disk → выбрать эту папку. Версия редактора: **6000.6.0f1**. Открыть `Assets/Scenes/BestStop.unity` и нажать Play.

## Управление

- WASD или стрелки — перемещение по парковке в четырёх направлениях.
- Shift — бег.
- R — вернуть персонажа на старт.
- Esc — пауза / продолжить.
- F1 — показать / скрыть подсказки.
- F11 — переключить полноэкранный / оконный режим.

Персонаж ограничен зоной перед магазином и не может заходить в нарисованный фасад. При движении вверх (W / ↑), в том числе по диагонали, персонаж поворачивается спиной. Вниз — лицом, влево — зеркальным профилем. После остановки направление сохраняется в idle-анимации. Интерфейс изначально скрыт, чтобы не закрывать арт.

## Изображение

Игра запускается на весь экран в разрешении монитора. Новая композиция рассчитана на 16:9: весь магазин виден сразу, без полос и обрезки по бокам. Генератор выдал фон 1672×941; он отображается в сцене 2048×1152 единиц и масштабируется под разрешение экрана. На экранах с другими пропорциями камера заполняет экран и при необходимости следует за персонажем. Для спрайтов отключены фильтрация и сжатие. F11 переключает оконный режим.

Пять облаков движутся с разными скоростями. После полного ухода за край каждое появляется с другой стороны. Пауза останавливает облака вместе с персонажем.

В неподвижной стойке персонаж дышит (цикл 3 секунды) и слегка покачивается (цикл 4 секунды). Idle-анимация процедурная, на существующем спрайте: ноги остаются на месте, направление взгляда сохраняется. При ходьбе включаются кадры движения, на паузе idle также останавливается.

Рост персонажа настроен относительно входной двери: 150 единиц сцены вместо прежних 102. Масштаб одинаков для переднего, бокового и заднего вида; контактная тень увеличена под новый размер. Настройка: `CharacterHeight` в `BestStopGame.cs`.

## Исходники и сборка

Лес теперь отдельный: **Environment → Forest** содержит два дальних слоя и **Near trees** с отдельными елями. Префабы находятся в `Assets/Prefabs/Forest`. [Настройка леса](Documentation/EDITING-FOREST.md).

- `Assets/Scripts/BestStopGame.cs` — сцена, управление, анимация, камера, пауза.
- `Assets/Editor/BuildBestStop.cs` — Windows-сборка сохранённой сцены без сброса расстановки.
- `Assets/Editor/PrepareEditableScene.cs` — начальная подготовка редактируемого окружения.
- `Assets/Art/Forest/StoreForeground.png` — активный слой магазина и земли, прозрачный на месте леса и неба.
- `Assets/Art/Forest/DistantForest.png` и `SpruceTrees.png` — новые спрайты дальнего леса и отдельных елей.
- `Assets/Art/StoreBackground.png` — предыдущий фон, сохранён как референс.
- `Assets/Art/Sprites` — четыре независимых Sprite-ассета.
- `Assets/Prefabs/Props` — префабы PhoneBooth, IceMachine, TrashBin, YellowBollard.
- `Assets/Resources/BestStop.png` — оригинальный арт пользователя.
- `Assets/Resources/BestStopWide.png` — новый фон 16:9 без нарисованных облаков.
- `Assets/Resources/BestStopFlatProps.png` — предыдущий фон с нарисованными предметами, сохранён как референс.
- `Assets/Resources/Cloud.png` — прозрачный спрайт движущихся облаков.
- `Assets/Resources/Traveler.png` — прозрачный лист персонажа.

Меню редактора **Best Stop → Build Windows (keep scene layout)** собирает сохранённую сцену без пересоздания. Двигайте, дублируйте и удаляйте объекты в **Environment → Props** вне Play Mode, затем сохраняйте сцену Ctrl+S. Полная инструкция: [Редактирование предметов](Documentation/EDITING-PROPS.md).

Для проверки запуска: `BestStop.exe --smoke-test -logFile smoke.log`. Проверка выполняет движение, проверяет ограничения, кадры, движение и циклическое возвращение облаков, полную композицию 16:9, сохраняет `preview.png` рядом с exe и закрывает игру. Успех обозначается `BEST_STOP_SMOKE_PASS` в журнале.

Спрайт персонажа создан встроенным image_gen; промпт сохранён в `Documentation/character-prompt.txt`. Он визуально приближен к референсу; полное совпадение манеры художника не гарантируется.

Фон и облака также созданы встроенным image_gen. Промпты и размеры сохранены в `Documentation/environment-prompts.txt`.
